Episode 1: Web Architecture & Networking Basics

Notes & Key Takeaways by Abhishek

🌐 1. History of the Web (Web 1.0 to Web 3.0)

Web 1.0 (Read-Only Era)

1990s ka shuruati internet. Isme websites static hoti thi (sirf text aur basic images). User sirf information read kar sakta tha (jaise online encyclopedia ya digital newspaper). Koi login, interaction ya content creation nahi tha.

Web 2.0 (Read + Write / Interactive Era)

Aaj ka modern internet (YouTube, Instagram, Facebook). Isme User-Generated Content hota hai — har koi content publish, like aur share kar sakta hai. Data central tech giants ke servers par store hota hai.

Web 3.0 (Read + Write + Own / Decentralized Era)

Blockchain aur smart contracts par based internet. Yahan central companies ke control ke bina users ke paas apne data, identity aur digital assets ka direct ownership hota hai.

💻 2. How Computers Communicate With Each Other

  • Protocols (Rules): Computers aapas me baat karne ke liye pre-defined rules use karte hain jinhe Protocols kehte hain (e.g., HTTP, HTTPS, TCP/IP).
  • Client-Server Architecture:
    • Client: Request bhejne wala device (e.g., aapka browser ya smartphone).
    • Server: 24/7 chalne wala powerful computer jo request accept karke website/data wapas bhejta hai.
  • Data Packets: Badi files ya pages ek saath nahi bheje jaate, balki chhote-chhote chunks (packets) me split hokar travel karte hain aur destination par wapas assemble hote hain.

🌍 3. How Computers Send Data All Over the World

  • Submarine Cables (Undersea Fiber Optics): Internet satellite se kam aur samundar ke neeche bichhi hui lakho kilometer lambi optical fiber cables se 99% chalta hai.
  • Speed of Light: Data glass fiber ke andar light pulses (photons) ke form me travel karta hai, isliye transatlantic transfer milliseconds me ho jata hai.
  • Routers & Switches: Raste me packets ko traffic control karke unke destination tak sabse fast raste se deliver karte hain.

🔍 4. Domain Name, IP, MAC Address & Routing

  • Domain Name: Insaan ke yaad rakhne ke liye website ka readable naam (e.g., sheryians.com, google.com).
  • IP Address (Logical Address): Internet par connected har device ka virtual identity/address (e.g., 142.250.190.46). Network badalne par IP change ho sakta hai.
  • MAC Address (Physical Address): Network Card (NIC) ka permanent hardware address jo manufacturer assign karta hai. Yeh device ka permanent fingerprint hai.
  • Routing: Data packets ko source se destination tak pahunchane ke liye sabse efficient route choose karne ka process.

⚡ 5. How ISP and DNS Work Together to Deliver Data

ISP (Internet Service Provider): Airtel, Jio, etc., jo aapke device ko physical internet network se connect karte hain.

DNS (Domain Name System): Internet ki phonebook jo domain names (jaise google.com) ko computer ke samajhne yogya IP address me translate karti hai.

🔄 Workflow: Jab aap browser me website open karte ho:
  1. Aap browser me sheryians.com type karke Enter dabate ho.
  2. Request aapke ISP ke paas jaati hai.
  3. ISP DNS Server se query karta hai: "sheryians.com ka IP address kya hai?"
  4. DNS server specific IP address return karta hai.
  5. ISP us IP address wale server se HTML, CSS aur JS files fetch karke aapke browser me render kar deta hai.
