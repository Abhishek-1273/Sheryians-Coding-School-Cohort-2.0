🌐 1. What is HTTP & Its Evolution (Versions)

HTTP (HyperText Transfer Protocol) Application Layer ka ek niyam (protocol) hai jo Web par browsers aur servers ke beech files (HTML, images, JSON) transfer karne ke liye use hota hai.

HTTP ke Major Versions:

  • HTTP/1.0 (1996): Har ek image ya CSS mangwane ke liye ek naya TCP connection khulta tha aur band hota tha. Bohot slow tha!
  • HTTP/1.1 (1997 - The Baseline): Keep-Alive introduce kiya gaya. Ek hi connection me multiple requests bheji ja sakti hain. Saaloon tak internet ispar chala.
  • HTTP/2 (2015): Multiplexing feature aaya! Ek hi TCP connection me multiple requests aur responses parallel me travel kar sakte hain bina wait kiye. Header compression (HPACK) aaya.
  • HTTP/3 (Modern Era): TCP chhod kar QUIC (UDP-based) protocol par shift ho gaya! TCP ka connection delay khatam kar diya aur ultra-fast mobile roaming support laya.

🔒 3. What is HTTPS & Why is it Better than HTTP?

HTTPS = HTTP + Secure (SSL/TLS Encryption). Yeh standard port 443 par chalta hai (jabki HTTP port 80 par chalta hai).

Kyun Better Hai? (The 3 Pillars):

  • 1. Encryption (Privacy): HTTP me data Plain-Text me jata hai (jaise postcard, koi bhi Wi-Fi hacker password padh sakta hai). HTTPS me data scramble ho jata hai (jaise sealed locker).
  • 2. Data Integrity: Raste me koi hacker ya ISP aapki website ke code me ads ya malware inject nahi kar sakta.
  • 3. Authentication: Prove karta hai ki aap jis bank ya website par ho, woh asli website hai, koi fake clone nahi.
  • SEO Boost: Google HTTPS websites ko ranking me higher priority deta hai.

🔑 4. How HTTPS Works & What is SSL/TLS Encryption?

SSL (Secure Sockets Layer) purana version tha, jise ab replace karke modern TLS (Transport Layer Security) use hota hai (currently TLS 1.3).

🔄 TLS Handshake Flow:
  1. Client Hello: Browser server ko support kiye jane wale encryption methods bhejta hai.
  2. Server Certificate: Server apna Digital SSL Certificate (with Public Key) bhejta hai, jo ek trusted authority (jaise Let's Encrypt ya DigiCert) se signed hota hai.
  3. Key Exchange (Asymmetric): Browser Public Key se ek secret Session Key encrypt karke bhejta hai. Server use apni Private Key se decrypt karta hai.
  4. Symmetric Encryption: Ab dono ke paas same Session Key hai. Aage ka saara HTML/CSS/JSON is session key se super-fast encrypt hota hai!

🔄 5. Proxy vs Reverse Proxy (Crucial Interview Concept)

Parameter Forward Proxy (Normal Proxy) Reverse Proxy
Kiske aage baithta hai? Client ke aage (Client-side). Server ke aage (Server-side).
Kiski identity chupata hai? Client ki (Website ko client ka real IP nahi dikhta). Server ki (Client ko asli backend servers ka IP nahi pata hota).
Main Use Case College/Office me blocked websites access karna, browsing anonymize karna. Load Balancing, SSL Termination, Caching, DDoS Protection (e.g. Nginx, Cloudflare).
💡 One-Liner Yaad Rakhne Ka Tarika:

Forward Proxy client ki privacy bachata hai; Reverse Proxy server ko bachata aur traffic sambhalta hai!

🛡️ 6. How VPN Works & Accessing Restricted Content

VPN (Virtual Private Network) aapke device aur internet ke beech ek Encrypted Tunnel create karta hai.

VPN Kaise Kaam Karta Hai?

  • Aapka device data ko encrypt karta hai aur seedha VPN Server (e.g. USA ya Singapore) ko bhejta hai.
  • Aapka local ISP (Airtel/Jio) sirf encrypted garbage dekhta hai — unhe yeh nahi pata chalta ki aap kaunsi website visit kar rahe ho.
  • VPN Server us request ko target website tak bhejta hai. Website ko lagta hai ki request USA se aayi hai, isliye Geo-Restricted content (jaise kisi doosre desh ki Netflix library ya blocked services) easily unlock ho jata hai.
