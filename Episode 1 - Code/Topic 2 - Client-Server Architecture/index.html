🏛️ 1. What is Client-Server Model?

Client-Server Model ek distributed network architecture hai jisme work do main components ke beech divide hota hai:

  • Client (Service Requester): Woh device ya application jo data ya service ke liye request bhejta hai.
  • Server (Service Provider): Woh centralized machine jo requests ko sunta hai, process karta hai aur response return karta hai.
💡 Restaurant Analogy:

Aap (Customer) = Client (Khana order karte ho / Request bhejte ho).

Waiter = HTTP Protocol (Aapka order kitchen tak le jata hai).

Kitchen (Chef) = Server (Khana ready karta hai aur aap tak bhejta hai / Response deta hai).

⚖️ 2. Client vs Server: Main Differences

Parameter Client (e.g. Chrome, Firefox) Server (Hosting Machine)
Primary Role Requests bhejta hai aur UI render karta hai. Requests sunta hai, process karta hai aur data serve karta hai.
Availability Jab user chahe tab on/off hota hai. 24/7/365 bina ruke online rehta hai.
Hardware & Location User ka laptop, mobile, tablet. High-end Data Centers me secure cloud servers.
Code Execution Browser me HTML, CSS, JavaScript run hoti hai. Node.js, Python, Databases, Business logic run hoti hai.

🔄 3. How HTTP Request & Response Cycle Works

Browser aur Server ke beech communication HTTP (HyperText Transfer Protocol) ke niyam (rules) par chalta hai:

1. HTTP Request (Browser ➡️ Server):

  • HTTP Methods:
    • GET : Server se data/page mangwana (e.g. website kholna).
    • POST : Server par naya data bhejna (e.g. login form, sign up).
    • PUT / PATCH : Existing data update karna.
    • DELETE : Data delete karna.
  • Headers: Request ke baare me metadata (e.g., Browser type, Authentication tokens, Content-Type).

2. HTTP Response (Server ➡️ Browser):

  • Status Codes (Result status):
    • 200 OK : Request successful rahi, data mil gaya.
    • 301 / 302 Redirect : Page kisi doosre link par move ho gaya.
    • 404 Not Found : Server par mangi hui file/page maujood nahi hai.
    • 500 Internal Server Error : Server ke code ya database me koi gadbad ho gayi.
  • Response Body: Real content jo browser display karega (HTML, CSS, JSON, Images).

🚀 4. What Happens When You Visit a Website?

Jab aap browser address bar me URL likhte ho (jaise https://sheryians.com):

  1. URL Input: User ne browser me address type kiya aur Enter dabaya.
  2. DNS Lookup: Browser ISP aur DNS phonebook se puchta hai: "sheryians.com ka IP kya hai?" DNS IP address (e.g. 104.21.x.x) return karta hai.
  3. TCP / SSL Handshake: Browser us IP par secure connection establish karta hai (3-way handshake + HTTPS security certificate verify karta hai).
  4. HTTP GET Request: Browser server ko bolta hai: "Mujhe homepage ka HTML de do."
  5. Server Response: Server request process karke 200 OK ke sath index.html bhejta hai.
  6. Parsing & Rendering: Browser HTML padhta hai, link kiye huye CSS aur JS download karta hai, aur visual web page screen par draw (render) karta hai.

🎨 5. Front-end vs Back-end

Parameter Front-end (Client-Side) Back-end (Server-Side)
Kya hota hai? Website ka look, feel aur visual interface jo user ko dikhta hai. Parde ke peeche ka dimag (business logic, security & database).
Technologies HTML5, CSS3, JavaScript, React, Tailwind. Node.js, Express, Python, Java, MongoDB, PostgreSQL.
Focus Area UI/UX, Responsiveness, Animations, User Experience. APIs, Authentication, Server performance, Data storage.
Kahan chalta hai? User ke browser ke andar. Remote cloud server par.

📄 6. Static Websites vs Dynamic Websites

Static Websites:

  • Fixed pre-written files (HTML, CSS, JS) hoti hain.
  • Har user ko bilkul **same content** dikhta hai chahe koi bhi kab bhi visit kare.
  • Koi database ya server processing ki jarurat nahi hoti.
  • Examples: Portfolio sites, documentation pages, restaurant menus.

Dynamic Websites:

  • Content database aur user ke according **on-the-fly change** hota hai.
  • Har user ko alag data dikh sakta hai (e.g. logged-in profile, cart items).
  • Server-side scripting aur databases ke sath interact karti hain.
  • Examples: Instagram, Amazon, Netflix, YouTube.

☁️ 7. What is Web Hosting & How It Works?

Web Hosting ek aisi service hai jisme ek hosting company apne powerful servers par aapki website ki files (HTML, CSS, JS, images) ko store karne ki space provide karti hai.

  • Kaise kaam karta hai? Server high-speed internet se 24/7 connected rehta hai. Jab koi user aapka domain type karta hai, hosting server turant us user ko aapki files deliver kar deta hai.
  • Common Hosting Types:
    • Shared Hosting: Ek hi server ke resources kai websites aapas me share karti hain (budget-friendly).
    • VPS (Virtual Private Server): Server par dedicated virtual slice milti hai.
    • Dedicated Server: Pura physical server sirf aapki ek website ke liye reserve hota hai.
    • Modern Cloud Platforms: Vercel, Netlify, Render, AWS, Google Cloud (auto-scaling & instant deployment).
