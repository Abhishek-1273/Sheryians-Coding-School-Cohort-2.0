Dynamic Selectors

1. Pseudo-Classes & Pseudo-Elements

Pseudo-classes (:) target elements in a specific temporary state. Pseudo-elements (::) let you style virtual sub-elements or inject content without cluttering your HTML.

1.1 Pseudo-Classes (:hover, :focus, :active)

  • :hover → Triggers when the mouse cursor enters the element.
  • :focus → Triggers when an element (like an input or button) receives keyboard or click focus.
  • :active → Triggers at the exact moment the element is being clicked down.

1.2 Pseudo-Elements (::before & ::after)

Inserts cosmetic virtual elements before or after the element's actual content. Always requires content: "";.

2. CSS Transitions & Timing Curves

True 3D Space

3. 3D Transforms (Perspective, translate3d, rotate3d)

By setting perspective on a parent container, we unlock the Z-axis (depth). Elements can pop out toward the viewer or recede into the screen!

3.1 Core 3D Functions

  • perspective: 800px; → Defines how far the viewer is from the 3D plane (creates optical depth).
  • translateZ(50px) → Pulls element closer to your eyes along the Z-axis.
  • rotateX(45deg) • rotateY(45deg) • rotateZ(45deg) → Rotates along 3D axes.
  • transform-style: preserve-3d; → Keeps child elements in true 3D space instead of flattening them.

Autonomous Motion

4. CSS Animations (@keyframes)

Unlike transitions (which need a user trigger like :hover), Animations run automatically, loop infinitely, and navigate through complex multi-step intermediate keyframes (0% → 50% → 100%).

Anatomy of an Animation: @keyframes pulseGlow {
  0% { transform: scale(1); opacity: 0.8; }
  50% { transform: scale(1.15); opacity: 1; }
  100% { transform: scale(1); opacity: 0.8; }
}
