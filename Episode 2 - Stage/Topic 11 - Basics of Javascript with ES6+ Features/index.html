04

What are Statements and Semicolons in JS?

JavaScript me likhi gayi har complete instruction jo koi action perform karti hai, use Statement kehte hain.

Semicolons (;) ka kya role hai?
Semicolon ek statement ka end (khatma) mark karta hai. Jaise English me sentence ke baad full stop (.) lagta hai, waise hi JS me statement ke baad ; lagaya jata hai.

ASI (Automatic Semicolon Insertion):
JavaScript me agar aap semicolon ; lagana bhool bhi jaate ho, toh browser ka JavaScript engine internally khud semicolon add kar deta hai (ise ASI bolte hain). Lekin best practice yahi hai ki aap explicitly semicolon lagao taaki kabhi edge-cases me unexpected bugs na aayein.
Statements & Semicolons 
let score = 100;    // Statement 1: Variable declare kiya aur 100 assign kiya
score = score + 10; // Statement 2: Calculation karke re-assign kiya
console.log(score); // Statement 3: Output print karne ka instruction

Variables & Keywords: var, let, const

Variable ek container hota hai jisme hum apna data store karte hain taaki program me aage use kar sakein. Modern JavaScript me variables declare karne ke 3 keywords hain:

Feature var (Legacy ES5) let (Modern ES6) const (Modern ES6)
Scope Function scoped (block {} ke bahar leak ho jata hai) Block scoped (apne {} ke andar locked rehta hai) Block scoped (apne {} ke andar locked rehta hai)
Re-declaration Allowed (same naam dobara — risky) Not allowed (ek naam se ek hi banega) Not allowed (ek naam se ek hi banega)
Re-assignment Allowed (value badal sakte ho) Allowed (value change ho sakti hai) Not allowed (value fixed rahegi)
Hoisting Hoisted, default undefined Hoisted, par TDZ (Dead Zone) me Hoisted, par TDZ (Dead Zone) me
Best Practice Avoid (use mat karo) Use (jab value aage change ho) Default choice (hamesha use karo)
script.js 
// 1. var - Re-declaration aur Re-assignment dono allowed hain
var a = 10;
var a = 20; // Re-declare ho gaya bina kisi error ke

// 2. let - Re-declare nahi ho sakta, sirf re-assign hota hai
let age = 22;
age = 23;     // Allowed (Value change ho gayi)
// let age = 25; // Error: Identifier 'age' has already been declared

// 3. const - Na re-declare hoga, na value change hogi
const PI = 3.14;
// PI = 3.15; // Error: Assignment to constant variable
07

Variable Hoisting in JavaScript

Hoisting kya hota hai?
JavaScript code run hone se pehle ek Creation Phase (Memory Allocation) se guzarta hai. Is phase me JavaScript engine saare variable aur function declarations ko scope ke top par move (hoist) kar deta hai.

Keyword Hoisting Behavior Declare karne se pehle access kiya toh?
var Top par hoist hota hai aur turant undefined se initialize ho jata hai. undefined print hota hai (koi error nahi aata!).
let & const Hoist hote hain, par initialize nahi hote. Wo Temporal Dead Zone (TDZ) me rehte hain. ReferenceError: Cannot access variable before initialization error aata hai!
Hoisting Examples 
// 1. var ke sath hoisting:
console.log(x); // Output: undefined (Error nahi aaya!)
var x = 10;

// 2. let aur const ke sath (Temporal Dead Zone):
// console.log(y); // Uncaught ReferenceError: Cannot access 'y' before initialization
let y = 20; // Yahan TDZ khatam hua, ab y accessible hai
TDZ (Temporal Dead Zone) kya hai?
Scope shuru hone se lekar jab tak let ya const variable ki actual declaration line execute nahi ho jaati, us beech ke time-period ko Temporal Dead Zone kehte hain. Is zone ke andar variable ko access karna strictly mana hai.

JavaScript Data Types: Primitive vs Relative (Reference)

JavaScript ek Dynamically Typed language hai — iska matlab hume variable banate waqt uska data type (jaise int, string) explicitly likhna nahi padta, value assign hone par JS engine khud type decide karta hai.

1. Primitive Data Types

Direct Value (Stack Memory)

Ye immutable (unchangeable) hote hain. Variable me inki direct original value store hoti hai. Copy karne par bilkul nayi independent copy banti hai.

Types: number, float (number), string, boolean, null, undefined, Symbol, BigInt

2. Relative / Reference Data Types

Address / Reference (Heap Memory)

Inhe Relative ya Reference types kehte hain kyunki ye actual value store karne ke bajaye memory (Heap) ke address se relate (point) karte hain. Copy karne par address share hota hai.

Types: Array [], Object {}, Function ()

Data Type Category Example typeof Result Asaan Explanation (Hinglish)
number Primitive 42, -10 "number" Saare integers (positive, negative, zero) number type me aate hain.
float Primitive 3.14, 99.99 "number" Important: JS me float alag se koi keyword ya data type nahi hota! Decimal values bhi internally number (64-bit float) hi hoti hain.
string Primitive "Abhishek", 'Cohort' "string" Text data jise quotes ya backticks me likha jata hai.
boolean Primitive true, false "boolean" Sirf do values hoti hain: true (haan/sahi) ya false (nahi/galat). Condition check me use hota hai.
null Primitive null "object" ⚠️ Developer ne explicitly bataya hai ki ye variable khali (empty) hai. (typeof "object" aana JS ka historic bug hai).
undefined Primitive undefined "undefined" Variable declare kar diya par usme abhi tak koi value assign nahi ki.
Symbol Primitive Symbol("id") "symbol" ES6 feature: Hamesha ek unique aur immutable identifier create karta hai jo kisi dusre Symbol se match nahi hota.
BigInt Primitive 9007199254740991n "bigint" Bohot bade integers jo normal number ki safe limit (2^53 - 1) se bade hote hain. End me n lagta hai.
array Reference [10, 20, "JS"] "object" Multiple values ka ordered list jo square brackets [] me store hota hai aur index 0 se shuru hota hai.
object Reference { name: "Abhi" } "object" Key-value pairs ka group jo curly braces {} me likha jata hai. Real-world data store karne ke liye sabse important hai.
Primitive (Value) vs Relative (Reference) Memory Behavior 
// 1. PRIMITIVE DATA TYPE (Call by Value):
let x = 100;
let y = x; // y ko x ki nayi copy mili
y = 200;   // y ko change kiya
console.log(x); // 100 -> x bilkul safe hai, change nahi hua!

// 2. RELATIVE / REFERENCE DATA TYPE (Call by Reference):
let originalArray = ["HTML", "CSS"];
let copyArray = originalArray; // copyArray ko memory address (reference) mila

copyArray.push("JavaScript"); // copyArray me add kiya
console.log(originalArray); // ["HTML", "CSS", "JavaScript"] -> originalArray bhi change ho gaya!

Some Important Values: undefined, null, NaN, Infinity

JavaScript me 4 special values aksar confuse karti hain:

Value Matlab (Simple Hindi) Typeof Result Example
undefined Variable declare kar diya par abhi tak koi value assign nahi ki (JS ki default value). "undefined" let x; console.log(x);
null Developer ne explicitly bataya hai ki ye dabba jaan-boojh kar "khali" (empty) hai. "object" (JS ka historic bug!) let user = null;
NaN Not a Number: Invalid mathematical operation ka result (jaise string ko number se multiply karna). "number" "apple" * 5 // NaN
Infinity Jab koi calculation mathematical limit se bahar ho jaye (jaise kisi number ko 0 se divide karna). "number" 10 / 0 // Infinity
undefined vs null interview question:
undefined == null returns true (loose comparison, dono falsy hain).
undefined === null returns false (strict comparison, kyunki dono ka type alag hai).

Working with Strings & Core Methods

JavaScript me text data ko String kehte hain, jise quotes '...', "..." ya backticks `...` me likhte hain.

Important Concept: Strings JavaScript me immutable hoti hain — matlab koi bhi string method original string ko directly modify nahi karta, hamesha ek nayi string return karta hai.

String Methods Practice 
let str = "Sheryians Coding School";

// 1. slice(start, end) -> String ka ek hissa cut karke nikalta hai
// Note: End index include nahi hota (0 se 9 matlab 0 se 8 tak)
console.log(str.slice(0, 9)); // "Sheryians"

// 2. Template Strings (ES6 Backticks ``) -> Clean string formatting
let student = "Abhishek";
let course = "Cohort 2.0";
let msg = `Hello ${student}, welcome to ${course}!`; // ${} se direct variables inject hote hain
console.log(msg);

// 3. split(separator) -> String ko tod kar Array me convert karta hai
console.log(str.split(" ")); // ["Sheryians", "Coding", "School"]

// 4. replace(old, new) -> Pehle matching word ko replace karta hai
console.log(str.replace("Coding", "Development")); // "Sheryians Development School"

// 5. includes(search) -> Check karta hai ki word string me present hai ya nahi (true/false)
console.log(str.includes("Coding")); // true
console.log(str.includes("Python")); // false
Interview Question: slice() vs splice() me kya difference hai?
Ye interview ka bohot popular trick question hai! Strings par sirf slice() hota hai, splice() method nahi hota!
splice() strictly Arrays ka method hai jo original array ke andar se elements ko add/remove karta hai. Strings immutable hoti hain, isliye strings par splice() exist hi nahi karta.

Basic Operators in JavaScript

Operators wo symbols hote hain jo variables aur values par mathematical, comparison ya logical operations perform karte hain.

Category Operators Examples & Meaning
Arithmetic +, -, *, /, % (modulus/remainder), ** (exponent/power) 10 % 3 // 1 (Remainder)
2 ** 3 // 8 (2 ki power 3)
Assignment =, +=, -=, *=, /= x += 5 matlab x = x + 5
Increment / Decrement ++ (pre/post increment), -- (pre/post decrement) x++ (pehle use karo, baad me badhao)
++x (pehle badhao, phir use karo)
Comparison == (loose), === (strict type check), !=, !==, >, <, >=, <= 5 == "5" // true (Sirf value check)
5 === "5" // false (Value + Type check)
Logical && (AND), || (OR), ! (NOT) true && false // false
true || false // true
!true // false
Bitwise & (AND), | (OR), ^ (XOR), ~ (NOT), <<, >> Bits level par calculation: 5 & 1 // 1 (0101 & 0001)
Operators Demo 
// Comparison: == vs ===
console.log(10 == "10");  // true  (Type coercion: string number me convert ho gaya)
console.log(10 === "10"); // false (Strict check: number !== string)

// Increment behavior
let count = 5;
console.log(count++); // 5 print hua (Post-increment: agle line se 6 hoga)
console.log(count);   // 6

// Logical Operator
let isLoggedIn = true;
let hasPermission = false;
console.log(isLoggedIn && hasPermission); // false
