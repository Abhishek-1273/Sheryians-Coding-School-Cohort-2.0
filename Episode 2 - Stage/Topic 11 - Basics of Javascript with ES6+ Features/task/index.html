Expressions vs Statements

Q9.1 - Q9.5: Type 5 + 10, type let x = 10;, which gives value immediately? Test let y = (5 + 10) * 2; console.log(y), aur 1-line difference.
Code Snippet Type Console REPL Output Reason
5 + 10 Expression 15 Expression turant execute hokar concrete value deta hai.
let x = 10; Statement undefined Statement sirf ek action/order perform karta hai, value return nahi karta.
let y = (5 + 10) * 2; Statement containing Expression console.log(y) → 30 (5 + 10) * 2 expression 30 bana, jo variable y me store hua.
One-Line Difference: "An Expression produces/evaluates to a value, while a Statement performs an action/instruction."

Special Values (undefined, null, NaN, Infinity)

Log 1 / 0, 0 / 0, Number("abc"), undefined + 1. Write what appears, aur 1-line explanation of null vs undefined.
Operation Result Output Typeof Result Why it occurs?
1 / 0 Infinity "number" Division by zero exceeds mathematical limit.
0 / 0 NaN "number" 0 divided by 0 is mathematically undefined (Not a Number).
Number("abc") NaN "number" Non-numeric characters cannot convert into a number.
undefined + 1 NaN "number" undefined coerces to NaN in arithmetic addition.
Null vs Undefined (One-Line Difference):
"undefined means a variable has been declared but not assigned any value (system default), whereas null is an intentional assignment representing an explicitly empty or non-existent value (developer's choice)."

Primitive vs Reference (Relative) Types

Q12.1: let x = 5; let y = x; y = 10; console.log(x, y)
Q12.2: let obj1 = { name: "Abhi" }; let obj2 = obj1; obj2.name = "Sheryians"; console.log(obj1.name)
Q12.3: Observe which one changes together.
Q12.4: Visualize with memory boxes (Stack vs Heap).
Primitive (Call by Value)

Stack Memory Box

x = 5 aur y = 10. Har variable ka apna alag independent memory box hota hai. y ko change karne se x par koi farak nahi padta.

Result: x = 5, y = 10

Reference (Call by Reference)

Heap Memory Pointer

obj1 aur obj2 dono Stack me sirf memory address store karte hain jo Heap ke same ek hi object { name: ... } ko point karta hai.

Result: obj1.name becomes "Sheryians"!
