01

Conditionals in JavaScript: if, else, else-if

JavaScript me Conditionals ka use code ka flow control karne ke liye kiya jata hai. Inki madad se program alag-alag situations (conditions) ke aadhar par alag-alag decisions leta hai.

if Block

Single Decision

Agar di gayi condition true hoti hai, tabhi iske andar ka code block execute hota hai.

else Block

Fallback Alternative

Jab if condition false ho jaye, tab else block automatically run hota hai.

else-if Ladder

Multiple Conditions

Jab do se zyada conditions check karni ho (e.g. grading system: A, B, C, Fail).

conditionals-demo.js 
let marks = 82;

if (marks >= 90) {
    console.log("Grade: A+");
} else if (marks >= 75) {
    console.log("Grade: A"); // Ye execute hoga!
} else if (marks >= 60) {
    console.log("Grade: B");
} else {
    console.log("Grade: Needs Improvement");
}
02

Ternary Operator (? :)

Ternary Operator simple if-else statement ka ek-line clean alternative hota hai. Isme 3 operands hote hain: Condition, Expression if True, aur Expression if False.

Syntax Traditional if-else Ternary Equivalent
condition ? expr1 : expr2 if (age >= 18) { status = "Adult"; } else { status = "Minor"; } let status = age >= 18 ? "Adult" : "Minor";
ternary-demo.js 
let userRole = "admin";
let welcomeMsg = userRole === "admin" ? "Dashboard Access Granted" : "Welcome, Guest!";
console.log(welcomeMsg); // "Dashboard Access Granted"

// Nested / Chained Ternary (Multiple Conditions):
let score = 85;
let result = score >= 90 ? "Excellent" : score >= 70 ? "Good" : "Average";
console.log(result); // "Good"
03

The switch Statement

Jab kisi ek specific variable ki value ko multiple options (cases) ke sath compare karna ho, toh lamba if-else likhne ke bajaye switch statement use karna zyada readable aur fast hota hai.

Crucial Rule: break aur Fallthrough kya hai?
Har case ke end me break; lagana zaroori hota hai. Agar aap break; lagana bhool jaate ho, toh agle saare cases bina condition match hue bhi execute ho jaate hain — is behavior ko Fallthrough kehte hain!
switch-demo.js 
let day = 3;

switch (day) {
    case 1:
        console.log("Monday");
        break;
    case 2:
        console.log("Tuesday");
        break;
    case 3:
        console.log("Wednesday"); // Match hua -> Ye execute hoga!
        break;
    case 4:
        console.log("Thursday");
        break;
    case 5:
        console.log("Friday");
        break;
    default:
        console.log("Weekend!"); // Agar koi case match na ho
        break;
}

Truthy & Falsy Values in JavaScript

JavaScript me jab bhi aap kisi condition (if, ternary, ya while) me koi non-boolean value pass karte hain, JS engine automatically us value ko true ya false me convert karta hai. Is basis par har value do categories me aati hai: Truthy aur Falsy.

Falsy Values (Sirf Ye 7)

Jo False Ban Jaati Hain

false, 0 (and -0 / 0n), "" (empty string), null, undefined, NaN, aur document.all.

Truthy Values (Baaki Sab!)

Jo True Ban Jaati Hain

Upar ki 7 falsy values ko chhod kar JS me har cheez truthy hai — jaise "0", "false", " " (space), [], aur {}!

Classic Interview Traps (Dhyan Rakhna!):
"" (empty string) Falsy hai, par " " (ek space) ya "false" string Truthy hoti hai! Isi tarah empty array [] aur empty object {} bhi Truthy hote hain.
truthy-falsy-demo.js 
// Check karne ke liye Boolean(value) ya if() use kar sakte hain:
if ("") {
    console.log("Ye nahi chalega"); // "" is Falsy
} else {
    console.log("Empty string Falsy hai!");
}

if ("0") {
    console.log('"0" ek non-empty string hai -> Truthy!'); // Ye chalega!
}

if ([]) {
    console.log("Empty array [] bhi Truthy hota hai!"); // Ye chalega!
}

console.log(Boolean(0));         // false
console.log(Boolean(null));      // false
console.log(Boolean(undefined)); // false
console.log(Boolean(NaN));       // false
console.log(Boolean("false"));   // true (kyunki string khali nahi hai)

The for Loop in JavaScript

Loop kya hota hai? Jab hume kisi kaam ko baar-baar repeat karna ho bina baar-baar code copy-paste kiye, tab hum Loop ka use karte hain.

for loop sabse common loop hai jisme 3 parts ek hi line me aate hain: Initialization, Condition, aur Increment / Decrement.

for-loop-demo.js 
// Syntax: for (initialization; condition; increment/decrement)
for (let i = 1; i <= 5; i++) {
    console.log("Iteration number:", i);
}

// Dry Run:
// i = 1 (1 <= 5 true)  -> print 1, i badhkar 2 hua
// i = 2 (2 <= 5 true)  -> print 2, i badhkar 3 hua
// i = 3 (3 <= 5 true)  -> print 3, i badhkar 4 hua
// i = 4 (4 <= 5 true)  -> print 4, i badhkar 5 hua
// i = 5 (5 <= 5 true)  -> print 5, i badhkar 6 hua
// i = 6 (6 <= 5 false) -> Loop terminated!
06

The while Loop in JavaScript

while loop ek Entry-Controlled Loop hai. Iska matlab hai ki code run hone se pehle hi condition check hoti hai. Agar shuru me hi condition false hui, toh loop ek bar bhi execute nahi hoga.

for loop vs while loop kab use karein?
Jab hume pehle se pata ho ki loop kitni baar chalana hai (e.g. 10 bar), tab for loop best hota hai.
Jab hume iterations ka count nahi pata ho par sirf ek condition pata ho (e.g. jab tak user correct password na dale), tab while loop best hota hai.
while-loop-demo.js 
let count = 1; // Initialization bahar hota hai

while (count <= 3) { // Condition check pehle hoti hai
    console.log("Count is:", count);
    count++; // Increment/Decrement loop ke andar manually karna padta hai
}
// Output: 1, 2, 3

The do...while Loop in JavaScript

do...while loop ek Exit-Controlled Loop hai. Iski sabse badi khasiyat ye hai ki ye kam se kam ek baar zaroor chalta hai, chahe condition pehle se hi false kyun na ho!

do-while-demo.js 
let num = 10;

do {
    console.log("Ye kam se kam 1 bar zaroor chalega! Num is:", num);
    num++;
} while (num < 5); // 11 < 5 false hai, par pehli bar execute ho chuka!

forEach in JavaScript

forEach Arrays ka ek built-in higher-order method hai. Ye array ke har ek element par ek callback function ko run karta hai. Isme hume index ya length manage karne ki zaroorat nahi padti.

Note: forEach kuch return nahi karta (iska return value undefined hota hai) aur iske andar break ya continue kaam nahi karta!
foreach-demo.js 
const techSkills = ["HTML", "CSS", "JavaScript", "SASS"];

// element, index, complete array
techSkills.forEach(function(skill, index) {
    console.log(`Index ${index}: ${skill}`);
});

// Arrow function syntax (ES6):
techSkills.forEach((skill) => console.log("Skill:", skill));

The for...in Loop (Iterating Objects)

for...in loop kisi Object ki Keys (Properties) ke upar iterate (loop) karne ke liye banaya gaya hai.

const student = {
    name: "Abhishek",
    cohort: "2.0",
    city: "Bhopal",
    language: "JavaScript"
};

// cohort : 2.0
// city : Bhopal
// language : JavaScript

Loop Main Purpose Kya deta hai? Best Used For

Loop Control Statements: break & continue

Loops ke natural execution flow ko modify karne ke liye do keywords use hote hain:

break

Stop & Exit Immediately

Loop ko turant wahi par khatam karke loop se bahar nikal deta hai.

continue

Skip Current & Next Step

Sirf current iteration ko skip karke agle round (iteration) par jump karta hai.

break-continue-demo.js 
// 1. break Example: 3 aate hi loop band ho jayega
for (let i = 1; i <= 5; i++) {
    if (i === 3) {
        console.log("Breaking loop at 3!");
        break;
    }
    console.log("break test i:", i);
}
// Output: 1, 2, "Breaking loop at 3!" (4 aur 5 nahi aayenge)

// 2. continue Example: 3 ko skip karke 4 aur 5 chalega
for (let j = 1; j <= 5; j++) {
    if (j === 3) {
        console.log("Skipping 3!");
        continue; // 3 ke liye neeche ka code run nahi hoga
    }
    console.log("continue test j:", j);
}
// Output: 1, 2, "Skipping 3!", 4, 5

Recursion in JavaScript

Recursion kya hai? Jab koi function khud apne aap ko call kare kisi problem ko chhote hisson me todne ke liye, use Recursion bolte hain.

1. Base Case (Rukne Ki Shart)

Must Have Stop Condition

Wo condition jahan par function khud ko call karna band kar deta hai. Agar Base Case na ho, toh infinite loop ban jayega!

2. Recursive Step

Function Calling Itself

Har step par input ko chhota karke function dubara call hota hai taaki wo Base Case ki taraf pahuche.

Stack Overflow Kya Hai?
Har function call JavaScript ke Call Stack me memory leti hai. Agar hum Base Case likhna bhool jayein, toh function infinite times call hota rahega aur browser ka Call Stack bhar jayega, jisse RangeError: Maximum call stack size exceeded (Stack Overflow) crash ho jata hai!
recursion-demo.js 
// Classic Example 1: Countdown from N to 1
function countDown(n) {
    // 1. BASE CASE (Rukne ka rule)
    if (n <= 0) {
        console.log("Done!");
        return;
    }

    console.log(n);
    // 2. RECURSIVE CALL (Naya chhota input)
    countDown(n - 1);
}
countDown(3); // Prints: 3, 2, 1, "Done!"

// Classic Example 2: Factorial of a Number (5! = 5 * 4 * 3 * 2 * 1)
function factorial(n) {
    if (n === 1 || n === 0) return 1; // Base case
    return n * factorial(n - 1);       // Recursive step
}
console.log("Factorial of 5:", factorial(5)); // 120
