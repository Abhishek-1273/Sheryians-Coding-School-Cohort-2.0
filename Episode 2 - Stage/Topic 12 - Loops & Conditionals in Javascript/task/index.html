02

Variable & Function Hoisting in JavaScript

(a) Predict output: console.log(a); var a = 10;
(b) Predict output: console.log(b); let b = 10;
(c) Predict output: test(); function test() { console.log("Hello"); }
(d) Function Expression call before initialization: hello(); var hello = function() { console.log("Hi"); }
(e) One-sentence rule: What gets hoisted? What does not get hoisted fully?
hoisting-solutions.js 
// (a) var Hoisting:
console.log(a); // Output: undefined (Error nahi aayega, kyunki sirf declaration hoist hui!)
var a = 10;

// (b) let Hoisting (Temporal Dead Zone):
// console.log(b); // ❌ ReferenceError: Cannot access 'b' before initialization
let b = 10;

// (c) Function Declaration Hoisting:
test(); // Output: "Hello" (Function apni poori body ke sath hoist hota hai!)
function test() { 
    console.log("Hello"); 
}

// (d) Function Expression Trap:
// hello(); // ❌ TypeError: hello is not a function!
var hello = function() { 
    console.log("Hi"); 
};

Detailed Explanation for (d):

Yahan hello ek var variable hai. Memory Creation Phase me JS engine hello ko hoist karke usme default undefined daal deta hai. Jab hum hello() call karte hain, toh asal me hum undefined() execute karne ki koshish kar rahe hote hain, isliye error aata hai: TypeError: hello is not a function.

(e) Final One-Sentence Rule:
"Function declarations apni poori definition ke sath fully hoist hote hain, jabki variables poori tarah hoist nahi hote — var sirf undefined ke sath hoist hota hai aur let/const Temporal Dead Zone (TDZ) me uninitialized rehte hain."

Conditional Operators (if, else, else-if, ternary, switch)

(a) Age prompt: age >= 18 → "Adult", else → "Minor".
(b) Marks grading: >=90 "A grade", >=75 "B grade", >=50 "C grade", else "Fail".
(c) City check: "Bhopal" → "MP", "Delhi" → "Capital", else → "Unknown City".
(d) Ternary operator: score = 40; score >= 35 ? "Pass" : "Fail".
(e) Convert if-else into ternary: temperature > 30 ? "Hot" : "Pleasant".
(f) Switch case for Day 1 to 7 with default "Invalid Day".
(g) Logical operator condition: age >= 18 && country === "India".
conditionals-solutions.js 
// (a) Age Check:
function checkAge(age) {
    if (age >= 18) {
        console.log("Adult");
    } else {
        console.log("Minor");
    }
}

// (b) Marks Grading Ladder:
function calculateGrade(marks) {
    if (marks >= 90) {
        return "A grade";
    } else if (marks >= 75) {
        return "B grade";
    } else if (marks >= 50) {
        return "C grade";
    } else {
        return "Fail";
    }
}

// (c) City Matcher:
let city = "Bhopal";
if (city === "Bhopal") {
    console.log("MP");
} else if (city === "Delhi") {
    console.log("Capital");
} else {
    console.log("Unknown City");
}

// (d) Score Ternary:
let score = 40;
let examResult = score >= 35 ? "Pass" : "Fail";
console.log("Exam Result:", examResult); // "Pass"

// (e) Temperature Ternary Conversion:
let temperature = 32;
let weatherType = temperature > 30 ? "Hot" : "Pleasant";
console.log("Weather:", weatherType); // "Hot"

// (f) Switch Case:
function getDayName(dayNumber) {
    switch (dayNumber) {
        case 1: return "Monday";
        case 2: return "Tuesday";
        case 3: return "Wednesday";
        case 4: return "Thursday";
        case 5: return "Friday";
        case 6: return "Saturday";
        case 7: return "Sunday";
        default: return "Invalid Day";
    }
}
console.log("Day 3 is:", getDayName(3)); // "Wednesday"

// (g) Voter Eligibility:
let userAge = 20;
let country = "India";
if (userAge >= 18 && country === "India") {
    console.log("Eligible for Vote");
} else {
    console.log("Not Eligible");
}
