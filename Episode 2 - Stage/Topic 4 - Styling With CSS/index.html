📏 2. Mastering CSS Units (Absolute vs Relative)

Unit Type Relative To Best Used For
px Absolute Fixed Screen Pixels Fine borders, fixed icons, box-shadows.
rem Relative Root Element (<html>) font-size (Default 1rem = 16px) Industry Standard for typography, padding & margins (Responsive!).
em Relative Parent element ka font-size Component-scoped scaling (e.g. icon relative to button text).
% Relative Parent container ka width/height Fluid grid columns, responsive card widths.
vw / vh Relative Viewport Width & Height (1vw = 1% screen width, 100vh = full screen height) Hero sections (min-height: 100vh), full-screen overlays.

CSS Math Functions (Modern Layout Magic):

  • min(50%, 500px) ➡️ Dono me se jo chhota hoga, use apply karega.
  • max(300px, 20vw) ➡️ Dono me se jo bada hoga, use apply karega.
  • clamp(1rem, 2.5vw, 2.5rem) ➡️ Responsive font size (Minimum, Preferred, Maximum limit).

📦 3. The CSS Box Model & Box Properties

Browser me har HTML element ek rectangle box hota hai jisme 4 layers hoti hain:

MARGIN (Outside element spacing)
BORDER (Visible outline boundary)
PADDING (Inside space between border & text)
CONTENT (Text, Image, Inner elements)

The Golden Property: box-sizing: border-box vs content-box

Property Value Total Width Calculation Formula Real Life Effect
content-box (Default) Total = width + padding + border Agar 200px box me 20px padding doge toh box 240px ka hokar layout tod dega! ❌
border-box (Best Practice) Total = exact specified width Padding aur border box ke andar adjust ho jate hain, layout kabhi nahi toot ta! ✅

💡 Border vs Outline (Interview Nuance):

border box model ka hissa hota hai aur space leta hai. Lekin outline box model ke bahar draw hoti hai aur page ka koi space occupy nahi karti (Focus indicators me use hoti hai).

🌄 5. Background Properties & Gradients

  • background-color : Solid ya transparent background color.
  • background-image: url('image.jpg') : Background me photo lagana.
  • background-size :
    • cover ➡️ Pura container fill karta hai (aspect ratio maintain karke, crop ho sakta hai).
    • contain ➡️ Puri image dikhata hai bina crop kiye (khali space chhoot sakti hai).
  • background-repeat: no-repeat ➡️ Image ko baar-baar tile hone se rokta hai.
  • background-position: center ➡️ Image ko horizontal aur vertical center karta hai.
  • background-attachment: fixed ➡️ Page scroll hone par bhi photo apni jagah freeze rehti hai (Parallax Effect!).

CSS Linear & Radial Gradients:

linear-gradient(135deg, #38bdf8, #a855f7, #f43f5e)
