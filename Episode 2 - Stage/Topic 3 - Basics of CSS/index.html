🎨 1. Introduction to CSS & Why It's Important

CSS (Cascading Style Sheets) ek presentation language hai jo batati hai ki HTML elements screen par visually kaise dikhenge.

💡 Human Body Analogy:

• HTML: Skeleton (Haddiyan / Kankaal) — sirf structure deta hai.

• CSS: Skin, clothes, hairstyle, makeup — appearance, layout aur sundarta deta hai.

• JavaScript: Muscles aur dimag — movement, logic aur action deta hai.

Cascading ka matlab kya hai?
Rules top to bottom "cascade" (jharna/flow) karte hain. Agar ek hi element par do same rules apply ho rahe hon, toh unki Specificity aur Order of Appearance decide karta hai ki kaunsa style jeetega.

📐 2. CSS Syntax, Selectors & Comments

CSS Rule Anatomy:

/* CSS Comment: Iska syntax yeh hota hai */
selector {
    property: value;   /* Declaration */
    color: #38bdf8;
    font-size: 16px;
}
  • Selector: HTML element jise style karna hai (e.g. h1, .card).
  • Property: Jo feature badalna hai (e.g. color, font-size).
  • Value: Property ko di gayi setting (e.g. red, 24px).
  • Declaration: Ek property: value; ke jode ko declaration bolte hain.

🔌 3. Three Ways to Add CSS to HTML

Method Syntax & Location When to Use & Pros/Cons
1. Inline CSS Element ke andar style="" attribute:
<p style="color: red;">Text</p>		 Avoid in production! Sirf quick testing ya emails ke liye. Highest priority hoti hai par maintain karna mushkil.
2. Internal CSS HTML ke <head> ke andar <style> tag:
<style> p { color: blue; } </style>		 Single page websites ke liye theek hai, par multiple pages me code duplicate ho jata hai.
3. External CSS Alag style.css file aur <link> tag:
<link rel="stylesheet" href="style.css">		 Industry Standard & Best Practice! Pura design ek hi jagah rehta hai aur browser cache kar sakta hai (fast loading).

🎯 4. Selectors & Specificity Hierarchy (Precedence)

Core Selectors:

  • Element Selector: p { color: white; } ➡️ Page ke sabhi <p> ko style karega.
  • Class Selector (.): .btn { padding: 8px; } ➡️ Multiple elements par reuse ho sakta hai (e.g. class="btn").
  • ID Selector (#): #navbar { background: black; } ➡️ Page par sirf ek unique element ke liye hota hai (e.g. id="navbar").

Specificity Ladder (Kaun Jeetega?):

1. !important ➡️ Sabhi rules ko tod kar zabardasti jeet jata hai (Use rarely!).

2. Inline Style (Score: 1000) ➡️ style="color: red;"

3. ID Selector (Score: 100) ➡️ #hero-banner

4. Class / Attribute / Pseudo-class (Score: 10) ➡️ .card, :hover

5. Element Selector (Score: 1) ➡️ p, div, h1

6. Universal Selector (Score: 0) ➡️ *

🔍 Specificity Battle Example:

p { color: white; }            /* Score: 1 */
.card-text { color: green; }   /* Score: 10 (Wins over element!) */
#special-text { color: gold; } /* Score: 100 (Wins over class!) */

✍️ 5. Mastering Text Styling in CSS

Text ke look and feel ko customize karne ke liye main CSS properties:

Property Common Values Purpose & Effect
font-family Inter, Roboto, sans-serif Font type/style set karta hai (hamesha fallback stack provide karo).
font-style normal, italic, oblique Text ko slant/italic karne ke liye.
font-weight normal, bold, 100-900 Text ki thickness/motai control karta hai (e.g. 700 = bold).
line-height 1.5, 1.8, 24px Lines ke beech vertical spacing (readability badhane ke liye).
text-decoration none, underline, line-through Underline ya strikethrough set/remove karta hai (links me none).
text-align left, center, right, justify Horizontal text alignment.
text-transform uppercase, lowercase, capitalize Casing change karta hai bina HTML text retype kiye.
letter-spacing 1px, 2px, 0.1em Characters/Letters ke beech ka horizontal gap.
word-spacing 4px, 10px Words ke beech ka horizontal gap.
text-shadow x-offset y-offset blur color Text ke peeche glowing ya 3D drop shadow effect deta hai.
