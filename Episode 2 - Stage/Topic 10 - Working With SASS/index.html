Core Fundamentals

1. What is SASS? (CSS Preprocessor)

Browsers can only understand standard CSS. Standard CSS lacks programming features like logic, variables, and reusability. SASS (Syntactically Awesome Style Sheets) is a CSS preprocessor that compiles down to clean, valid CSS before reaching the browser.

Syntax Comparison

2. SCSS vs SASS (Which One & Why?)

SASS has two distinct file formats and syntaxes. SCSS is the modern, universal industry standard!

Modern Standard (.scss)

SCSS (Sassy CSS)

Uses standard CSS curly braces {} and semicolons ;. Every valid CSS file is automatically valid SCSS!

// style.scss
$primary: #38bdf8;

.button {
  background: $primary;
  &:hover {
    background: darken($primary, 10%);
  }
}
Legacy Indented (.sass)

SASS (Original Syntax)

Uses indentation instead of braces and newlines instead of semicolons (like Python). Less common in teams.

// style.sass
$primary: #38bdf8

.button
  background: $primary
  &:hover
    background: darken($primary, 10%)
Workflow Guide

3. Setting Up the Environment for SCSS in VS Code

How do we automatically compile .scss to .css while we code?

Step 1

Install VS Code Extension

Search Extensions (Ctrl+Shift+X) for "Live Sass Compiler" (by Glenn Marks).

Step 2

Create style.scss

Create your stylesheet with the .scss extension instead of .css.

Step 3

Click "Watch Sass"

In the VS Code bottom blue status bar, click Watch Sass. It auto-generates style.css on every save!

Step 4

Link style.css in HTML

Always link the compiled style.css inside <head>, never the .scss file.

Language Features

4. The 4 Core Superpowers of SASS

Superpower 1

SASS Variables ($)

Define global colors, fonts, or padding once using the $ symbol. Change it in one spot to update the entire app!

$primary-color: #0284c7;
$border-radius: 12px;

.card {
  background: $primary-color;
  border-radius: $border-radius;
}
Superpower 2

Nesting & Parent Selector (&)

Nest CSS rules inside one another matching your HTML hierarchy. Use & to reference the immediate parent (essential for &:hover and BEM!).

.navbar {
  background: #111;
  a {
    color: #fff;
    &:hover { color: #38bdf8; }
  }
}
Superpower 3

Mixins (@mixin & @include)

Reusable blocks of styles that accept dynamic parameters like functions! Eliminates repetitive code.

@mixin flex-center($gap: 10px) {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: $gap;
}

.box { @include flex-center(20px); }
Superpower 4

Functions & Math Operators

Perform math directly in styles (+, -, *, /) and use built-in functions like lighten() and darken().

$base-padding: 8px;

.button {
  padding: ($base-padding * 2) ($base-padding * 3);
  background: darken(#38bdf8, 15%);
}
