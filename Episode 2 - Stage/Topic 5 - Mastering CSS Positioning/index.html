Core Concept

1. The 5 CSS Position Properties

By default, elements follow the Normal Document Flow (block elements stack vertically, inline elements sit side-by-side). The position property allows us to take elements out of normal flow or position them precisely.

1.1 position: static; (Default)

Default value for every HTML element. Follows natural document flow. Properties like top, bottom, left, right, and z-index have no effect.

Static Box (Default Flow)

1.2 position: relative;

Element is positioned relative to its own original position. Importantly: It leaves its original space intact in the document flow. Often used as an anchor parent for absolute children.

Original Ghost Spot
Shifted (top: 15px, left: 25px)

1.3 position: absolute;

Completely removed from document flow (surrounding elements act like it doesn't exist). Positioned relative to its nearest ancestor with a position other than static (usually a parent with position: relative). If none exists, it anchors to <body>.

Parent Container (position: relative)
Absolute Child (top: 15px, right: 15px)

1.4 position: fixed;

Removed from document flow and pinned relative to the Browser Viewport. It does not move when the user scrolls the page. (See floating badge in top-right corner!)

Fixed to Viewport (Stays during scroll)

1.5 position: sticky; (Hybrid)

Toggles between relative and fixed. It behaves like relative until the page reaches a specified scroll threshold (e.g. top: 0), then it "sticks" to the screen within its parent container.

Coordinates & Layers

2. Offset Properties (top, bottom, left, right) & z-index

Offset properties specify how far an element moves from its anchor point. z-index controls the stacking order along the 3D Z-axis (which element appears on top).

2.1 Offset Direction Rules

  • top: 20px; → Pushes element downwards by 20px from top edge.
  • bottom: 20px; → Pushes element upwards by 20px from bottom edge.
  • left: 20px; → Pushes element rightwards by 20px from left edge.
  • right: 20px; → Pushes element leftwards by 20px from right edge.

2.2 Stacking Order (z-index)

Only works on elements with position: relative / absolute / fixed / sticky (NOT on static unless flex/grid items).

Smooth Interactivity

4. CSS :hover & transition

Without transition, state changes (like hover) happen abruptly in 0ms. transition smoothly interpolates values over time.

Shorthand Syntax:

transition: [property] [duration] [timing-function] [delay];
transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
Gold Standard Interview Trick

5. Perfect Center Alignment with Absolute + Translate

How do you perfectly center a div inside any parent without Flexbox/Grid? The Classic Absolute Centering Formula:

Parent (position: relative)
PERFECTLY CENTERED top: 50%; left: 50%;
transform: translate(-50%, -50%);

Why does this work?

  1. top: 50%; left: 50%; moves the top-left corner of the element to the exact center of the parent.
  2. transform: translate(-50%, -50%); shifts the element backwards by 50% of its OWN width & height, pulling its center point right onto the coordinate!
