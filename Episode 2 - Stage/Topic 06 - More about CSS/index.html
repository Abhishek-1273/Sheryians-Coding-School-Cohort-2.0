Layout Fundamentals

1. Display Properties in CSS

The display property determines how an element renders in the document flow and behaves with respect to its surrounding siblings and dimensions.

1.1 display: block;

Starts on a new line and takes up the full width available. Supports width, height, margin, and padding on all 4 sides.

Block 1 (Full Width)
Block 2 (Starts on next line)
Examples: <div>, <p>, <h1-h6>, <section>

1.2 display: inline;

Flows within existing text without line breaks. Takes only necessary content width. Ignores width and height; vertical margins do not push siblings.

Inline A Inline B Inline C (side-by-side)
Examples: <span>, <a>, <strong>, <em>

1.3 display: inline-block;

The best of both worlds! Sits side-by-side like inline, but fully respects width, height, margin, and padding.

IB 1 (100x40px)
IB 2 (100x40px)
IB 3 (100x40px)
Examples: <button>, <input>, customized badges

1.4 display: none; vs visibility: hidden;

display: none; removes element completely from document flow (zero space occupied). visibility: hidden; hides element visually but preserves its physical layout space.

2. Complete FlexBox (Container Properties)

Flexbox is a One-Dimensional (1D) layout model designed to distribute space and align items along either a horizontal or vertical axis.

Main Axis & Cross Axis Concept:

When flex-direction: row; → Main Axis is Horizontal (X), Cross Axis is Vertical (Y).

When flex-direction: column; → Main Axis is Vertical (Y), Cross Axis is Horizontal (X).

2.1 flex-direction

Defines the direction of the Main Axis.

  • row (Default): Left to right
  • row-reverse: Right to left
  • column: Top to bottom
  • column-reverse: Bottom to top

Item-Level Rules

3. Flex Item Properties & Shorthands

Properties applied directly to the individual flex child items to customize sizing, growth, shrinking, and ordering.

3.1 flex-grow, flex-shrink & flex-basis

  • flex-grow: [number];: How much remaining positive space this item absorbs. (e.g. flex-grow: 2 grows twice as fast as 1).
  • flex-shrink: [number];: How much this item shrinks when space is negative/overflowing. 0 prevents shrinking!
  • flex-basis: [size];: Default initial size of the item before grow/shrink occurs (like ideal width).
The Master Shorthand: flex: <flex-grow> <flex-shrink> <flex-basis>;
flex: 1; → flex: 1 1 0%; (Evenly expands) flex: auto; → flex: 1 1 auto; flex: 0 0 250px; → Fixed sidebar width (never shrinks/grows)

3.2 order & align-self

  • order: [integer];: Rearranges the visual order of items without modifying HTML DOM order! Default is 0. Negative values move forward.
  • align-self: [align];: Overrides the parent container's align-items for this single specific item.

4. Introduction to CSS Grid (Flex vs Grid)

While Flexbox is 1-Dimensional (row OR column), CSS Grid is 2-Dimensional (handling rows AND columns simultaneously).

Flexbox (1D)

Best for linear content: Navbars, button rows, badge lists, single-direction component alignment.

CSS Grid (2D)

Best for page skeletons: Photo galleries, dashboard cards, complex editorial multi-row/multi-column layouts.

Core Grid Properties:

display: grid; grid-template-columns: repeat(3, 1fr); /* 3 equal columns */ gap: 16px; /* Row and column gutter */

5. Understanding CSS overflow

What happens when an element's content exceeds its defined width or height? The overflow property controls visibility and scrollbars.

5.1 overflow: visible; (Default)

Content bleeds outside the boundary box and overlaps other elements.

I am spilling out of my parent box! Notice how this content overflows the dashed boundary.

5.2 overflow: hidden;

Clips everything beyond the boundary. Great for circular avatars, card corners, and preventing layout breaks.

I am very long text that gets neatly clipped by my parent box!

5.3 overflow: scroll;

Always forces scrollbars (both X and Y), even if the content doesn't need them.

Scrollbars are permanently visible here.

5.4 overflow: auto; (Best Practice)

Adds scrollbars only when content overflows. Cleanest user experience.

Scroll inside me! Scrollbars only appear when content genuinely exceeds dimensions. Smooth and professional.

Directional Axes: overflow-x & overflow-y

You can independently control horizontal and vertical overflow: e.g. overflow-x: hidden; overflow-y: auto; (Standard for modal dialogs and scrollable dashboards).

6. Grouping Selectors & Nested (Combinator) Selectors

Writing clean, efficient, and scalable CSS by eliminating repetition and scoping styles precisely.

6.1 Grouping Selectors (DRY Principle)

When multiple selectors share identical styles, combine them with commas , to keep code Don't Repeat Yourself (DRY).

Example: h1, h2, h3, .custom-title {
  font-family: 'Poppins', sans-serif;
  color: #ffffff;
}

6.2 Nested & Combinator Selectors

Targeting elements based on their hierarchical relationship in the HTML tree.

  • Descendant Selector (Space): #card p
    Matches any <p> inside #card at any nesting level.
  • Child Selector (>): #card > p
    Matches only direct child <p> of #card (ignores grandchildren).
  • Adjacent Sibling (+): h2 + p
    Matches the <p> immediately following an <h2>.

💡 Why Do We Use Nested Selectors in Real Projects?

  1. Scoping & Modularization: Ensures styles for .nav a don't accidentally override links in .footer a.
  2. Eliminates Class Overload: Avoids having to put class="header-nav-list-item-link" on every single element.
  3. Clean DOM Hierarchy: Keeps CSS aligned with the semantic structure of your HTML.
