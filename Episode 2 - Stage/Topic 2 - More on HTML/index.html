🏷️ 1. Understanding Semantic Tags

Semantic Tags woh tags hote hain jinka naam padhte hi browser, developer aur search engine (Google) ko pata chal jata hai ki is tag ke andar kya content hai.

Purana tarika (Non-Semantic): Sab kuch <div> aur <span> me likhna (Div Soup).
Modern tarika (Semantic): Meaningful tags use karna.

Core Semantic Elements:

  • <header> : Page ya section ka introductory content, logo ya navigation.
  • <main> : Pura page ka primary, unique content (ek page par sirf ek hota hai).
  • <section> : Thematic grouping of content (jaise Features, Pricing, Testimonials).
  • <article> : Self-contained content jo independently distribute ho sakta hai (Blog post, News article, Comment).
  • <aside> : Main content se related secondary info (Sidebar, related links, ads).
  • <footer> : Bottom area (Copyright, contact links, social icons).
  • <form> : User input collect karne ka container.
  • <details> & <summary> : Collapsible accordion widget (bina JavaScript ke!).
  • <figure> & <figcaption> : Media with its official caption.

🧱 2. Block vs Inline Elements (Core Foundation)

Parameter Block-Level Elements Inline Elements
New Line Hamesha nayi line se shuru hote hain. Nayi line nahi lete, usi line me fit hote hain.
Width Available 100% full width cover karte hain. Sirf apne content ke barabar space lete hain.
Margin / Padding Top, bottom, left, right sabhi margins follow karte hain. Top & bottom margin/height follow nahi karte (left/right karte hain).
Common Examples <div>, <p>, <h1>-<h6>, <section>, <ul>, <table> <span>, <a>, <b>, <strong>, <img>, <code>

📊 4. Working with HTML Tables

Tabular data display karne ke liye standard structure:

  • <table> : Pura table wrapper.
  • <tr> : Table Row (Har row banata hai).
  • <th> : Table Header cell (Default bold aur center aligned).
  • <td> : Table Data cell (Normal content).
  • <thead>, <tbody>, <tfoot> : Table semantic sections.
  • colspan & rowspan : Multiple columns ya rows ko merge karne ke attributes.

📝 5. HTML Forms & Inputs

Form (<form>) ek interactive container hai jiske zariye user ka data (Login, Signup, Feedback, Payment) collect karke backend server ko submit kiya jata hai.

Essential Form Tags:

  • <form> : Pura form wrapper jo action aur method define karta hai.
  • <label> : Input field ka caption (for attribute input ke id se match karta hai, accessibility ke liye mandatory).
  • <input> : Single-line data lene ke liye self-closing versatile tag.
  • <textarea> : Multi-line text (e.g. comments, address).
  • <select> & <option> : Dropdown menu banane ke liye.
  • <button> : Clickable button (default type="submit").

Input Types Breakdown:

HTML5 me type attribute se input ka behavior decide hota hai:

  • text : Normal single-line text input.
  • number : Sirf numbers (min, max, step attributes ke sath).
  • tel : Phone number input (mobile me numeric keypad popup karta hai).
  • date : Native calendar date picker.
  • color : Color picker palette.
  • file : Device se files/images upload karne ke liye.
  • checkbox : Multiple options select karne ke liye.
  • radio : Single choice option (Sabhi radio buttons ka name attribute same hona zaroori hai!).
  • range : Slider control (volume, price filter).
  • submit : Form submit karne wala button.

Crucial Form Attributes:

  • action : Server ka URL / endpoint jahan data bheja jana hai.
  • method : Data transfer protocol (GET = URL me parameters dikhte hain; POST = Request body me safely jata hai).
  • name : Most Important! Backend server par data isi name ki key se pehchana jata hai (e.g. username="Abhishek").
  • required : Field ko mandatory banata hai (bina bhare submit nahi hoga).
  • placeholder : Khali input field ke andar light hint text.
  • target : Form submission response kis window me khulega (_self ya _blank).
  • novalidate : Browser ki default validation (jaise email check) ko bypass/disable karne ke liye.
  • enctype : Data encoding type. File upload ke liye enctype="multipart/form-data" mandatory hota hai!

🎬 6. Deep Dive into Media Tags (<audio>, <video> & <source>)

HTML5 me plugins (jaise Flash) ke bina directly audio aur video stream karne ke liye native tags hain.

Essential Media Attributes:

  • src : Media file ka path ya direct URL.
  • controls : Browser ke default play, pause, volume aur seek bar render karta hai.
  • autoplay : Page load hote hi video/audio chalu kar deta hai. (Note: Modern browsers bina muted ke autoplay allow nahi karte!).
  • muted : Video ya audio ko silent / mute start karta hai.
  • loop : Media khatam hone ke baad automatically wapas shuru se chalata hai.
  • width & height : Video player ke dimensions set karta hai.

Using <source> Tag for Multi-Format Codec Fallbacks:

Alag-alag browsers alag-alag video formats support karte hain. Multiple formats provide karne ke liye <source> tag use hota hai:

<video controls width="100%" poster="thumbnail.jpg">
    <source src="movie.webm" type="video/webm">
    <source src="movie.mp4" type="video/mp4">
    Your browser does not support the video tag.
</video>
💡 Browser Fallback Logic:

Browser upar se niche check karta hai: Agar WebM (jo fast aur highly compressed hai) support karta hai toh use chalayega; agar nahi, toh automatically MP4 par switch ho jayega!
