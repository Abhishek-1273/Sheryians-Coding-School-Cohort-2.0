🧱 1. Understanding HTML & Its Use Cases

HTML (HyperText Markup Language) kisi bhi website ka Skeleton (Dhaancha) hota hai.

  • HyperText: Aisa text jisme doosre pages ke links (Hyperlinks) embedded hote hain.
  • Markup Language: Yeh programming language nahi hai; yeh tags (<tag>) ke zariye browser ko batati hai ki kaunsa content heading hai, kaunsa paragraph hai, aur kahan image aayegi.
  • Analogy: HTML = Makaan ki eent aur cement (Structure), CSS = Paint aur interior design (Styling), JavaScript = Bijli ke switches aur pankhe (Functionality).

🏗️ 2. The Anatomy of an HTML Document

Har standard HTML document ka ek fixed boiler-plate structure hota hai:

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Page Title</title>
  </head>
  <body>
    <h1>Visible Content Goes Here</h1>
  </body>
</html>
  • <!DOCTYPE html> : Browser ko batata hai ki hum modern HTML5 use kar rahe hain.
  • <html> : Root element jisme pura webpage wrap hota hai.
  • <head> : Brain of the page — isme metadata, title, CSS links aate hain jo screen par visually nahi dikhte.
  • <title> : Browser ke tab bar par dikhne wala page ka naam.
  • <body> : Sabhi visible elements (text, images, buttons) body ke andar aate hain.

✍️ 3. Working with Text Elements

Headings (<h1> to <h6>):

H1 sabse important (aur sabse bada) hota hai, H6 sabse chhota. SEO ke liye ek page par sirf ek hi <h1> hona chahiye.

Paragraphs & Line Breaks:

  • <p> : Paragraph text ke liye block-level element.
  • <br> : Self-closing tag jo nayi line (line break) insert karta hai.

Inline Formatting & Code:

  • <span> : Inline container jo specific text ko style ya target karne ke kaam aata hai bina line break ke.
  • <code> : Inline code snippet dikhane ke liye monospace font use karta hai.
  • <pre> : Preformatted text — isme spaces aur newlines bilkul jaise type kiye gaye hain waise hi display hote hain!

🎬 5. Media Tags & HTML Attributes

Attributes tags ko extra information ya behavior provide karte hain (jaise src, alt, href):

1. Image Tag (<img> - Self Closing):

<img src="image.jpg" alt="Description" width="300" height="200">
  • src : Image ka file path ya online URL.
  • alt : Alternative text — agar image load na ho ya blind users screen-reader use karein toh alt text padha jata hai (SEO ke liye mandatory).
  • width & height : Image dimensions set karne ke liye.

2. Audio & Video Tags:

<audio controls src="audio.mp3"></audio>
<video controls width="400" src="video.mp4"></video>
  • controls : Play, pause aur volume buttons display karta hai.

🔗 6. Hyperlinks & Page Navigation

Webpages ko aapas me connect karne ke liye Anchor Tag (<a>) use hota hai:

  • href : Destination URL ya file path (e.g. href="about.html").
  • target="_blank" : Link ko ek naye tab me open karta hai.
  • target="_self" (Default) : Same tab me kholta hai.
